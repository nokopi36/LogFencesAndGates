# Log Fences and Gates 仕様書

- mod_id: `log_fences_and_gates` / パッケージ: `com.nokopi.logfencesandgates` / 作者: `nokopi` / ライセンス: MIT
- Minecraft 26.3 / NeoForge 26.3.0.42-beta（ベータ。正式版が出たら追従する）
- 連携 MOD: なし
- 利用範囲: 公開予定（CurseForge）

## 1. コンセプト
バニラの全種類の木に「原木（樹皮付き）の見た目のフェンスとフェンスゲート」を追加する。
斧で **柱・上の横木・下の横木を別々に** 剥けるので、樹皮のあり／なしを組み合わせて見た目をカスタマイズできる。

### 遊びの流れ
- 原木を集めて原木のフェンス・フェンスゲートをクラフトする
- フェンスを置いて繋げ、斧で好きな部位を右クリックして樹皮を剥ぐ（例: 柱は樹皮付きのまま、横木だけ剥いで明るくする）
- 性能はバニラのフェンスと同じで、純粋に建築・装飾のための MOD

## 3. 機能の詳細

### 3.1 原木のフェンス（優先度: MVP）
- 挙動: バニラの木のフェンス（`FenceBlock`）と同じ。隣のフェンス・フェンスゲート・ブロックに繋がり、リードを結べる
- 見た目: 柱は原木の側面テクスチャ、横木は原木の側面テクスチャを横向き（90°回転）にしたもの。テクスチャはバニラ（`minecraft:block/oak_log` / `stripped_oak_log`）を参照する
- 数値（バニラの木のフェンスと同じ）: 硬さ 2.0 / 爆発耐性 3.0 / 斧で速く壊せる / 燃える（真紅・歪んだは燃えない）/ かまどの燃料 300 tick
- 保持するデータ（blockstate、すべて初期値 `false`）:
  - `post_stripped` — 柱が剥がれているか
  - `upper_stripped` — 上の横木（全方向まとめて）が剥がれているか
  - `lower_stripped` — 下の横木（全方向まとめて）が剥がれているか
  - バニラのフェンスの状態（`north`/`east`/`south`/`west`/`waterlogged`）はそのまま
- タグ: `minecraft:wooden_fences`（バニラの木のフェンスと繋がる）、`minecraft:mineable/axe`
- **完了条件**: 原木のフェンスを並べると繋がり、バニラのオークのフェンスとも繋がる。見た目が原木になっている。斧で速く壊せて、壊すと自分がドロップする

### 3.2 部位ごとの樹皮剥ぎ（優先度: MVP）
- 操作: 斧を持ってフェンスを右クリックすると、**クリックした部位だけ**樹皮が剥がれる
  - 判定: クリック位置が柱の範囲（中央 4×4）→ 柱。それ以外は高さで、上下の横木の中間（y 10.5/16）より上 → 上の横木、下 → 下の横木（当たり判定は横木の隙間も含むため、近いほうの横木になる）
  - 横木がどこにも繋がっていない場合（柱だけ）は、どこをクリックしても柱を剥ぐ
  - すでに剥がれている部位をクリックしても何も起きない（斧も消費しない）
- 演出: バニラの原木を剥ぐときと同じ音（`AXE_STRIP`）、斧の耐久値 −1、腕を振る
- 剥いだ樹皮は元に戻せない（バニラと同じ）
- 実装方針: ブロックの `useItemOn` を上書きし、`BlockHitResult` のクリック位置から部位を判定する。斧の判定はアイテムの `minecraft:block_transformer` コンポーネントが `minecraft:axe` かどうか（26.3 では斧の剥ぎ処理がデータ駆動の BlockTransformer になり、クリック位置を受け取れないため）
- **完了条件**: 柱・上の横木・下の横木をそれぞれ斧で右クリックすると、その部位だけ剥がれた見た目になる。全 8 通りの組み合わせが作れる。ワールドを再読み込みしても見た目が保たれる

### 3.3 原木のフェンスゲート（優先度: MVP）
- 挙動: バニラの木のフェンスゲート（`FenceGateBlock`）と同じ。開閉・レッドストーン・塀に付いたときに下がる
- 開閉音: その木のバニラのフェンスゲートと同じ
- 部位ごとの樹皮剥ぎ: 4 部位（`post_stripped` = 両端の柱、`inner_stripped` = 扉の内側の縦木（左右まとめて）、`upper_stripped` = 扉の上の横木、`lower_stripped` = 扉の下の横木）。組み合わせ 16 通り
  - 判定（ゲートの長さ方向の位置 x、塀付きのときは高さを +3/16 補正）: 両端の柱（x 0〜2, 14〜16/16）→ 柱、内側の縦木（x 6〜10/16）→ 内側の縦木。それ以外は y 10.5/16 より上 → 上の横木、下 → 下の横木
- 開閉と樹皮剥ぎの区別: **閉じているとき**に斧を持って右クリック → クリックした部位を剥ぐ（その部位が剥がれ済みなら開閉）。開いているとき・斧以外 → 開閉（開いた扉は当たり判定の外にあり狙いにくいため）
- タグ: `minecraft:fence_gates`、`minecraft:mineable/axe`
- **完了条件**: ゲートを置いて開閉でき、原木のフェンスと繋がる。閉じたゲートの各部位を斧で剥げる。剥がれ済みの部位や開いたゲートを斧で右クリックすると開閉する。塀に付けても判定がずれない

### 3.4 全種類の木への展開（優先度: 次）
- MVP のオークで作った仕組みを、残り 11 種類に広げる（登録・datagen をループにする）
- **完了条件**: 全 12 種類のフェンスとゲートがクリエイティブタブにあり、それぞれ正しい原木の見た目で、剥ぐと正しい「樹皮を剥いだ原木」の見た目になる

### 3.5 樹皮を剥いだ原木からのクラフト（優先度: 次）
- 樹皮を剥いだ原木からクラフトすると、最初から全部位が剥がれた状態で置ける「剥いだ版」のフェンス・ゲートが手に入る
- 剥いだ版は別アイテム（ブロックは共通）: `stripped_<wood>_log_fence` / `stripped_<wood>_log_fence_gate`（ネザーは `stripped_crimson_stem_fence` など）
  - 表示名: Stripped Oak Log Fence ／ 樹皮を剥いだオークの原木のフェンス（ネザーはバニラに合わせ「表皮を剥いだ真紅の幹のフェンス」）
  - アイコンは剥いだ原木の見た目
- 置くと全部位（ゲートは 4 部位）が剥がれた状態になる
- ドロップ: 全部位が剥がれていれば剥いだ版、そうでなければ普通の版。ピックブロックも同じ
- クリエイティブタブ: 専用タブ・建築ブロックタブの両方で、各木の「フェンス → ゲート → 剥いだフェンス → 剥いだゲート」の順
- 燃料・燃えないタグなどは普通の版と同じ
- **完了条件**: 樹皮を剥いだ原木のレシピで作ったフェンス・ゲートを置くと最初から全部位が剥がれている。壊すと剥いだ版が戻り、一部だけ剥がれたものは普通の版が戻る

### 3.7 竹ブロックのフェンス（優先度: 次）
- 竹ブロック・表皮を剥いだ竹ブロックを材料に、他の木と同じ 4 アイテムを追加: `bamboo_block_fence` / `bamboo_block_fence_gate` / `stripped_bamboo_block_fence` / `stripped_bamboo_block_fence_gate`
  - 表示名: Bamboo Block Fence ／ 竹ブロックのフェンス、Stripped Bamboo Block Fence ／ 表皮を剥いだ竹ブロックのフェンス（バニラの「竹のフェンス」と区別）
- 音・開閉音は竹（`WoodType.BAMBOO`）、燃える・燃料 300 tick（バニラの竹のフェンスと同じ）
- 並び順: ポプラの後ろ、真紅の前。建築ブロックタブではバニラの竹のフェンスゲートの後ろ
- レシピ個数: 竹ブロック 1 = 板材 2 で換算し、フェンス 6 個・ゲート 2 個
- **完了条件**: 竹ブロックのフェンス・ゲートが他の木と同じように置け、剥げ、クラフトできる。レシピが 6 個・2 個

### 3.8 Diagonal Fences との連携（優先度: 次）
- Diagonal Fences（Fuzs）が入っているとき、原木のフェンスも斜めに繋がる。入っていなければ今までどおり（任意の依存）
- Diagonal Blocks の API `DiagonalBlockTypes.FENCE.registerBlockFactory(元のフェンスの ID, 作り方)` で、`DiagonalFenceBlock` を継承した独自の斜め版（剥ぎの状態・斧の処理・燃えやすさ・ピックブロックを持つ）を 13 種類分登録する
- 斜めの横木の見た目は Diagonal Fences が元のブロックステートの条件をコピー・回転して作るので、樹皮あり・なしも引き継がれる
- 部位の判定: 柱の範囲外は高さで上下の横木（斜めの横木も同じ）。斜め方向にだけ繋がっている場合も横木ありとして扱う
- ドロップ: 斜め版は元のルートテーブルを使うため、「全部位が剥がれているか」だけで判定する（ブロックの種類は条件に入れない）
- ゲートは Diagonal Fences の対象外なので変更なし
- **完了条件**: Diagonal Fences を入れると斜めに繋がり、斜めの横木も樹皮あり・なしが正しく表示され、斧で剥げる。全部剥いだものから剥いだ版がドロップする。Diagonal Fences を外しても起動・動作する

## 4. レシピ
| 結果 | 種類 | 材料・配置 | 優先度 |
|---|---|---|---|
| 原木のフェンス ×12 | 定形 | `L S L` / `L S L`（L = その木の原木、S = 棒）。バニラ（板材 4 + 棒 2 → 3 個）を原木 1 = 板材 4 で換算 | MVP |
| 原木のフェンスゲート ×4 | 定形 | `S L S` / `S L S`。バニラ（板材 2 + 棒 4 → 1 個）を同じく換算 | MVP |
| 全部位を剥いだフェンス ×12 / ゲート ×4 | 定形 | 上の L を樹皮を剥いだ原木にしたもの | 次 |

- 棒の数はバニラと同じなので、板材換算ではわずかにお得
- 竹ブロックは板材 2 枚分なので、フェンス ×6・ゲート ×2（3.7）
- `L` に「〜の木」（6 面樹皮のブロック）も使えるようにするかは未決定

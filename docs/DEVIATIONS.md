# SPEC からの変更履歴

| 日付 | 変更 | 理由 |
|---|---|---|
| 2026-10-03 | 表示名を「〜の原木の柵」→「〜の原木のフェンス」 | バニラの日本語名（オークのフェンス）に合わせる |
| 2026-10-03 | レシピ個数をフェンス 3 → 12、ゲート 1 → 4 | 原木 1 = 板材 4 の比率に合わせる（ユーザー判断） |
| 2026-10-03 | クリエイティブタブを建築ブロックのみ → 専用タブ + 建築ブロック | 24 ブロックを探しやすくしつつ、バニラの並びにも置く |
| 2026-10-03 | 木の種類にポプラを追加（11 → 12 種） | 26.3 で追加された新しい木 |
| 2026-10-03 | 樹皮剥ぎの実装方針を `getToolModifiedState` → ブロックの `useItemOn` 上書きに変更 | 26.3 で `ItemAbilities.AXE_STRIP` が廃止され、斧の剥ぎ処理はクリック位置を受け取らないデータ駆動の BlockTransformer になったため。挙動は SPEC どおり |
| 2026-10-03 | ゲートの剥ぎ部位を 3 → 4（内側の縦木を両端の柱から独立） | MVP を遊んだ感想。ゲートは木の本数が多いので、フェンスより細かくカスタマイズしたい（ユーザー判断） |

| 2026-10-04 | MOD 名を Log Fences → Log Fences and Gates に変更。mod_id `log_fences_and_gates`、パッケージ `com.nokopi.logfencesandgates`、jar 名・GitHub リポジトリ名も変更 | CurseForge に別作者の「Log Fences」（Forge 1.18.2〜1.20.1）があり、同名のプロジェクトを作れないため。ゲートもあることが伝わる名前にした（ユーザー判断）。配布前なのでブロック ID の変更による影響はない |
| 2026-10-11 | Diagonal Fences との連携を「いつか」→「次」（3.8）に。ドロップの条件からブロックの種類を外した | 公開後にユーザーが希望。斜め版のブロックは元のルートテーブルを使うため、ブロックの種類で判定すると剥いだ版が落ちない |
